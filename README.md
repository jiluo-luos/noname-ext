# 无名杀扩展云端仓库

本仓库每个子文件夹 = 一个无名杀扩展，文件夹名必须与扩展名完全一致。

## 结构

`
<扩展名>/
├── extension.js   ← 必需，扩展入口
├── info.json      ← 必需，含 name / intro / author
└── (其它资源：character/、image/、audio/ ...)
`

## 更新方式

游戏端扩展「云端更新」按**文件指纹**与本仓库逐文件比对：
指纹不同或本地缺失的文件会被下载覆盖，相同的跳过。
因此**修改扩展时不需要改版本号**，重新上传文件即可。

## 注意

- 不要提交 
ode_modules/、*.zip、备份文件
- 不要用 Git LFS（会导致指纹校验失败）
- .gitattributes 里的 * -text 用于禁止换行符自动转换，请勿删除
